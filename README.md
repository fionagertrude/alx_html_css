# Headphones - ALX Frontend Project

A responsive headphones landing page built with HTML, CSS, and JavaScript. Features a modern design with interactive elements, smooth animations, and mobile-friendly navigation.

## 🚀 Quick Start
1. Clone/download the project files
2. Ensure `images/` and `fonts/` folders are in place
3. Open `8-index.html` for the complete version
4. Resize browser to test responsiveness

## 📁 Project Structure
- **0-4 index.html/css**: Progressive build from header to footer
- **6-index.html/css**: CSS-drawn pentagons (no images)
- **7-index.html/css**: Animated version with effects
- **8-index.html/css/js**: Final version with hamburger menu

## ✨ Features
- **Responsive Design**: Mobile-first with hamburger menu (<480px)
- **CSS Animations**: Bounce, pulse, rotate, float, spin, shake effects
- **Interactive Elements**: Form validation, hover states, scroll animations
- **Pure CSS Graphics**: Pentagon shapes using clip-path
- **Clean Code**: CSS variables, BEM methodology, modular JavaScript

## 🛠 Technologies
- HTML5, CSS3, Vanilla JavaScript
- Flexbox & CSS Grid
- Intersection Observer API
- CSS Custom Properties

## 📱 Responsive Breakpoints
- Mobile: ≤480px (hamburger menu)
- Tablet: 481px-768px (2-column layouts)
- Desktop: ≥769px (4-column layouts)

## 🎯 Key Files
- `8-index.html` - Complete page with all features
- `8-styles.css` - All styles including animations
- `8-script.js` - Hamburger menu, form validation, scroll animations

**Demo:** Open `8-index.html` in your browser to see the full implementation!
